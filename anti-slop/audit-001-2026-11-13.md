# Audit UI 001 — T15-06 (antislop AFTER)

Rasio dihitung dengan `frontend/scripts/contrast.sh` (WCAG 2.x). Target: teks 4.5:1, teks besar/border kontrol/fokus 3:1.
Catatan: semua warna di bawah adalah warna asli AdminMart. Memperbaikinya berarti tampilan tidak lagi 100% identik.

## HIGH

1. **Teks muted `#9eabc0` = 2.32:1** (gagal bahkan untuk teks besar). Dipakai untuk label tabel, tanggal, MRN, keterangan.
   Usul: `--color-muted: #66738a` (4.79:1 di kartu, 4.62:1 di latar halaman).
2. **Teks putih di badge/tombol success `#22ca80` = 2.14:1, cyan `#01caf1` = 1.96:1, orange `#fb8c00` = 2.37:1.**
   Status "Selesai/Lunas/Siap" sulit dibaca. Usul: success `#128a55`_, cyan `#0b7a99`, orange `#b45309`.
   _`#128a55` = 4.38:1; untuk teks badge 12px tetap kurang 0.12 — pakai `#107c4c` bila ingin lolos penuh.
3. **Border input `#e9ecef` = 1.19:1** (butuh 3:1). Pengguna low-vision tidak melihat batas field form.
   Usul: `--color-line-input: #8a95a5` (3.03:1). Garis tabel/kartu dibiarkan (dekoratif).

## MEDIUM

4. **Teks body `#7c8798` = 3.64:1** (teks utama aplikasi). Usul: `#5b6676` (5.82:1).
5. **Primary `#5f76e8` = 4.01:1** — teks putih di tombol primer dan link biru di kartu. Usul: `#4a5fd6` (5.39:1), hover `#3a4fc4`.
6. **Danger `#ff4f70` = 3.18:1** (pesan error, badge "Gagal"). Usul: `#d42a4c` (4.96:1).
7. **Sidebar `#818181` = 3.90:1**, ditambah `opacity-70` pada item menu sehingga makin rendah. Usul: `#5f6670` (5.80:1), hapus opacity.
8. **Breadcrumb `#8392a5` = 3.06:1.** Usul: `#5e6b80` (5.20:1).

## LOW

9. **Target sentuh tombol `size="sm"`** (`px-2 py-1` ≈ 29px tinggi) di bawah 44px pada layar sentuh. Usul: `min-h-11` hanya di `pointer: coarse`, desktop tetap rapat.
10. **Tombol tutup Alert** (`px-4 py-3`, ikon kecil) ≈ 40px — tambah sedikit padding.

## Lolos

- Fokus keyboard: `:focus-visible` outline 2px primary (4.01:1 ≥ 3:1), skip link ada.
- Semua tombol/komponen interaktif sudah `cursor-pointer`; tombol ikon punya `aria-label`.
- Alert (warning/success/danger/info) semua ≥ 4.96:1; badge warning/light/dark/secondary lolos.
- `prefers-reduced-motion` dihormati; sidebar off-canvas di < 768px.
- 360px: belum diuji di browser nyata — tabel memakai wrapper `overflow-x-auto`, perlu cek manual di halaman Billing & Farmasi.

## Cara memperbaiki

Poin 1–8 cukup ubah token di `frontend/src/styles/globals.css` (satu file, tanpa ubah komponen).
Poin 7 juga hapus `opacity-70` di `AdminLayout.tsx`. Poin 9–10 di `Button.tsx` dan `Alert.tsx`.
